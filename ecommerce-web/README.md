## ✨ Features

| Feature | Description |
|---|---|
| 🛒 **Cart Management** | Add, remove & update cart items with real-time state sync |
| ❤️ **Product Favorites** | Save and manage favourite products via Context API |
| 📦 **Multi-Step Checkout** | 4-step checkout flow across 4 product categories |
| 🎞️ **Framer Motion** | Page transitions & micro-interactions across 6 key UI states |
| ✅ **Form Validation** | Schema-based validation via React Hook Form — 10+ error conditions |
| ⚡ **Lazy Loading** | Route-based code splitting for faster first-paint rendering |
| 📱 **Fully Responsive** | Seamless experience across all screen sizes |
| 🔐 **Auth Gate** | Protected routes with login redirect |

---

## 🚀 Performance Highlights

```
✦ Route-based code splitting → smaller async JS chunks
✦ Lazy loading → faster initial page load
✦ Framer Motion → zero layout shifts during transitions
✦ Context API → lightweight global state, no Redux overhead
```

## 🗂️ Checkout Flow

```
Step 1 → Personal Info      (name, email, phone)
Step 2 → Shipping Address   (city, street, zip)
Step 3 → Order Review       (items, totals, coupon)
Step 4 → Confirmation       (order placed ✅)
```

> Each step is validated with **React Hook Form** — submission is blocked on 10+ error conditions with inline user feedback.

## ⚙️ Getting Started

### Prerequisites

- Node.js `v18+`
- npm or yarn

### Installation

```bash
# 1. Clone the repo
git clone https://github.com/Fady519/Ecommerce-Website.git
cd Ecommerce-Website

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build & Deploy

```bash
npm run build
npm run deploy
```
